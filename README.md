# Find-Article-Text----
Анализ PDF научных статей и вычленение их них полезной информации

Принцип работы:
Программа анализирует PDF-документ, автоматически определяя, 
какой текст в нём содержит полезную информацию, а какой является частью оформления (колонтитулом, сноской, ссылкой и т.п.)

Как использовать:
1) Скачать проект
2) Поместить в папку проекта файл статьи для обработки
3) Запустить тетрадку
4) В папке сгенерируется txt-файл с результатом. Готово!

Проект находится на стадии MVP. Планируемые улучшения:
1) Улучшенная разбивка текста с помощью проверки правильности сентенизации
2) Улучшенная обработка форматов многоколоночной вёрстки текста
